# 个人工作台 - 部署与配置指南

## 一、快速预览（本地）

直接在浏览器中打开 `index.html` 即可使用。

如果使用本地文件协议，建议启动一个简单的 HTTP 服务器：

```bash
# Python
cd /path/to/workbench
python3 -m http.server 8080

# 或使用 Node.js
npx serve .
```

然后访问 http://localhost:8080

---

## 二、部署到公网（免费）

### 方案A：GitHub Pages（推荐）

1. 将 `workbench` 文件夹推送到 GitHub 仓库
2. 进入仓库 Settings → Pages → Source 选择 `main` 分支
3. 等待几分钟，访问 `https://你的用户名.github.io/仓库名/`

### 方案B：Vercel

1. 访问 vercel.com，用 GitHub 登录
2. Import 你的仓库，一键部署
3. 获得 `https://xxx.vercel.app` 域名

### 方案C：Netlify

1. 访问 netlify.com，拖拽 `workbench` 文件夹到部署区
2. 自动生成域名

## 三、配置微信云开发（云同步）

### 步骤1：注册微信云开发

1. 访问 https://cloud.weixin.qq.com/
2. 使用微信扫码登录
3. 点击「创建环境」，选择「免费体验」或「个人版」（19.9元/月）
4. 记下你的**环境 ID**（格式如 `your-env-xxx`）

### 步骤2：开启匿名登录

1. 进入云开发控制台 → 环境设置 → 登录授权
2. 开启「匿名登录」

### 步骤3：配置安全域名

1. 进入云开发控制台 → 环境设置 → 安全配置
2. 在「Web 安全域名」中添加：
   - 本地开发：`localhost:8080`
   - 公网部署：你的部署域名（如 `https://xxx.github.io`）
3. 保存后等待约 10 分钟生效

### 步骤4：创建数据库集合

在云开发控制台 → 数据库中创建以下集合（权限选择「仅创建者可读写」）：

```
tasks, events, notes, transactions, habits, birthdays, outfits, userConfig
```

### 步骤5：填入环境ID

1. 打开工作台 → 点击右上角 ⚙️ 设置
2. 点击「配置微信云开发」
3. 输入你的环境 ID
4. 点击保存，页面会自动刷新

> 刷新后，状态指示灯变绿即表示连接成功。之后手机和电脑数据将自动同步。

## 四、添加到手机桌面（PWA）

### iOS（Safari）
1. 在 Safari 中打开工作台网址
2. 点击底部「分享」按钮
3. 选择「添加到主屏幕」

### Android（Chrome）
1. 在 Chrome 中打开工作台网址
2. 点击右上角「⋮」→「添加到主屏幕」

---

## 五、数据管理

- **导出**：设置 → 数据管理 → 导出数据（JSON 文件）
- **导入**：设置 → 数据管理 → 导入数据（选择 JSON 文件）
- **清空**：设置 → 数据管理 → 清空本地数据（建议先导出备份）

---

## 六、常见问题

**Q: 为什么手机和电脑数据不同步？**
A: 检查：1) 是否配置了微信云开发环境ID；2) 安全域名是否添加了你的域名；3) 匿名登录是否开启。

**Q: 本地版能用吗？**
A: 可以。不配置云同步的情况下，所有数据存在浏览器本地 IndexedDB 中，导出/导入功能可手动迁移数据。

**Q: 如何新增板块？**
A: 设置 → 板块管理 → 勾选要启用的板块。拖拽可调整顺序。
